## Step 3 — Backend Setup

### 3a. Create the backend folder and virtual environment

```bash
mkdir backend
cd backend
python -m venv venv
```

Activate the virtual environment:

```bash
# Windows
venv\Scripts\activate

# Mac / Linux
source venv/bin/activate
```

### 3b. Install dependencies

Create `backend/requirements.txt`:

```text
fastapi==0.111.0
uvicorn[standard]==0.29.0
google-generativeai==0.7.2
python-dotenv==1.0.1
```

Then install:

```bash
pip install -r requirements.txt
```

### 3c. Create the environment file

Create `backend/.env` (never commit this file):

```text
GEMINI_API_KEY=your_api_key_here
FRONTEND_ORIGIN=http://localhost:5500
```

Add `.env` to `.gitignore`:

```bash
echo ".env" >> ../.gitignore
echo "*.db" >> ../.gitignore
echo "venv/" >> ../.gitignore
```

### 3d. Run the backend

```bash
cd backend
uvicorn main:app --reload --port 8000
```

Expected output:

```text
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Application startup complete.
```

### 3e. Verify the backend is working

Open in browser or run with curl:

```bash
curl http://localhost:8000/api/mentors
curl http://localhost:8000/api/dashboard/stats
```

You should see JSON responses with seed data.

Interactive API docs (auto-generated by FastAPI):

```text
http://localhost:8000/docs
```

## Step 4 — Frontend Setup

No build tools needed. The frontend is a single HTML file.

### 4a. Open in browser

Option A — just open the file directly:

```text
Open: version1/index.html in your browser
```

Option B — use VS Code Live Server (recommended, enables hot reload):

1. Install the **Live Server** extension in VS Code
2. Right-click `version1/index.html` → **"Open with Live Server"**
3. It opens at `http://127.0.0.1:5500`

### 4b. Set the API base URL

Find this line near the top of `version1/index.html`:

```js
const API_BASE = 'http://localhost:8000';
```

Leave it as-is for local development. You will update it to the Cloud Run URL before deploying.

### 4c. Verify frontend connects to backend

1. Make sure backend is running (`uvicorn main:app --reload`)
2. Open the frontend in browser
3. The mentor sidebar should load real names from the API
4. Open browser DevTools → Network tab → look for calls to `localhost:8000`

## Step 6 — Deploy Backend to Cloud Run

Run from the project root:

```bash
gcloud run deploy startconnector-api \
  --source ./backend \
  --region asia-southeast1 \
  --allow-unauthenticated \
  --set-env-vars GEMINI_API_KEY=your_api_key_here
```

This will:

1. Build a Docker container from `backend/Dockerfile`
2. Push it to Google Container Registry
3. Deploy it to Cloud Run in Singapore (`asia-southeast1`)

On success, it prints your live API URL:

```text
Service URL: https://startconnector-api-xxxx-as.a.run.app
```

**Update `API_BASE` in `version1/index.html` to this URL before deploying the frontend.**

## Step 7 — Deploy Frontend to Firebase Hosting

### 7a. Initialise Firebase Hosting (first time only)

```bash
firebase init hosting
```

When prompted:

| Prompt | Answer |
| --- | --- |
| Which Firebase project? | Select your GCP project |
| Public directory? | `version1` |
| Single-page app? | `No` |
| Overwrite index.html? | `No` |

This creates `firebase.json` in the project root.

### 7b. Deploy

```bash
firebase deploy --only hosting
```

On success:

```text
Hosting URL: https://[project-id].web.app
```

### 7c. Update CORS on the backend

Add your Firebase URL to the `FRONTEND_ORIGIN` env var on Cloud Run:

```bash
gcloud run services update startconnector-api \
  --update-env-vars FRONTEND_ORIGIN=https://[project-id].web.app \
  --region asia-southeast1
```

## Common Problems

| Problem | Fix |
| --- | --- |
| `ModuleNotFoundError: fastapi` | Virtual environment not activated — run `venv\Scripts\activate` first |
| CORS error in browser | Backend `FRONTEND_ORIGIN` doesn't include your frontend URL |
| Gemini returns 403 | API key is wrong or not set in `.env` |
| `firebase: command not found` | Run `npm install -g firebase-tools` first |
| Cloud Run deploy fails | Run `gcloud auth login` and check `gcloud config get-value project` |
| `index.html` shows blank page | Check browser console — likely a JS error on an API call |
| API returns 500 | Check Cloud Run logs: `gcloud run services logs read startconnector-api` |
